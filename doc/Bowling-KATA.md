# 볼링 점수 계산 (The Bowling Game Kata)

## 문제 설명

미국식 텐핀 볼링(American Ten-Pin Bowling) 한 게임의 유효한 투구 순서가 주어졌을 때, 해당 게임의 최종 총점을 계산하는 프로그램을 작성하십시오.

가벼운 연습(Kata)을 위해 아래 사항들은 고려하지 않습니다.

- 투구가 유효한지 확인하지 않습니다.
- 투구 횟수나 프레임 수가 정확한지 확인하지 않습니다.
- 중간 프레임의 점수를 제공하지 않습니다.

실제 애플리케이션에서는 위 기능들이 필요하겠지만, 여기서는 핵심 로직에 집중하기 위해 생략합니다.

---

## 볼링 점수 규칙 요약

볼링 게임은 총 **10개 프레임**으로 구성됩니다. 각 프레임에서 플레이어는 10개의 핀을 쓰러뜨리기 위해 두 번의 투구(Roll) 기회를 가집니다.

프레임 점수는 쓰러뜨린 총 핀 수에 스트라이크와 스페어에 따른 보너스를 더해 계산합니다.

| 상황 | 조건 | 보너스 |
|------|------|--------|
| **스페어 (Spare)** | 두 번의 투구로 10개 핀을 모두 쓰러뜨림 | 다음 1회 투구에서 쓰러뜨린 핀 수 |
| **스트라이크 (Strike)** | 첫 번째 투구에서 10개 핀을 모두 쓰러뜨림 (프레임 1회 투구 종료) | 이후 2회 투구에서 쓰러뜨린 핀 수의 합 |
| **10번 프레임** | 스페어 또는 스트라이크 기록 시 추가 투구 허용 | 최대 3회 투구 가능 |

---

## 요구사항 (Requirements)

다음 두 가지 메서드를 가진 `Game` 클래스를 작성하십시오.

```cpp
class Game {
public:
    void roll(int pins);  // 투구 시마다 호출. pins: 쓰러뜨린 핀 수
    int  score();         // 게임 총점 반환
};
```

### `void roll(int pins)`

- 플레이어가 공을 던질 때마다 호출됩니다.
- 인자값 `pins`는 해당 투구에서 쓰러뜨린 핀의 수입니다.

### `int score()`

- 게임의 총점을 계산하여 반환합니다.
- 스트라이크·스페어 보너스를 포함한 최종 합산 점수를 반환합니다.

## 점수 계산 예시

| 시나리오 | 투구 순서 | 총점 |
|----------|-----------|------|
| 거터 게임 (Gutter Game) | 20회 연속 0 | 0 |
| 올 원 (All Ones) | 20회 연속 1 | 20 |
| 스페어 (One Spare) | 5, 5, 3, 0, … (0으로 나머지) | 16 |
| 스트라이크 (One Strike) | 10, 3, 4, 0, … (0으로 나머지) | 24 |
| 퍼펙트 게임 (Perfect Game) | 12회 연속 10 (스트라이크) | 300 |
